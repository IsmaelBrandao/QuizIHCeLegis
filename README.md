# Quiz IHC & Legislação

Simulado estático com 80 questões de Ética, Legislação e Interação Humano-Computador para estudantes de Análise e Desenvolvimento de Sistemas.

## Conteúdo

- 40 questões de Ética e Legislação
- 40 questões de Interação Humano-Computador
- modo treino com correção imediata
- modo simulado com resultado ao final
- questões e alternativas embaralhadas
- revisão comentada e retomada dos erros
- desempenho separado por disciplina
- layout responsivo para computador e celular

## Publicar no GitHub Pages

1. Envie os arquivos desta pasta para a raiz de um repositório no GitHub.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, pasta `/ (root)` e salve.

O projeto usa somente arquivos estáticos e não precisa de etapa de compilação.
